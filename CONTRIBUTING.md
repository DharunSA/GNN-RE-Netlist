# Contributing to GNN-RE Implementation

Thank you for your interest in contributing to this project!

## How to Contribute
1. **Fork the repository** and create a new branch for your feature or bug fix.
2. **Ensure your environment matches** the required dependencies (Python 3.6.8, TensorFlow 1.12.0 or PyTorch 1.1.0, GraphSAINT).
3. **Write clear, well-documented code** for any modifications to the netlist parsing or graph construction.
4. **Test your changes** using the provided `Interconnected-Modules` dataset to ensure regressions are avoided.
5. **Submit a Pull Request** with a detailed explanation of your changes and any new metrics/benchmarks.

## Issue Reporting
If you encounter bugs, missing dependencies, or have feature requests (e.g., expanding Verilog netlist parsing for different technology libraries), please open an issue with:
- System and environment details
- Steps to reproduce the issue
- Relevant logs and error messages
